Accommodations per student · per class

▾ show
Set once per student, per class — never per assignment. A handicap, not extra credit: the standard stays where it is, the entry point moves. Every accommodation carries a written reason, and no adjusted score goes above 100%.
Open policy question, not a build question: the offsets below run 0–100%. On Thursday's slide the cap was +10% on a category. Decide which before this ships — an uncapped offset is a different instrument than a handicap.

Templates app feature

▾ show
The class type suggests a starting template. Save your own, load it, copy one type's template into another class. Worked example: a Foundational class still has a final that should be judged like portfolio work — so save a copy of the Portfolio weights as Class Final and use it for that one assignment.
What this page still doesn't show: the 1–10 sliders faculty actually touch during critique, and the timestamped voice notes tied to the video. Those live in Chris's app — this page is the layer underneath it.

Categories 1–3 are objective-ish. Category 4 is deliberately the subjective one — which is why it carries almost nothing in Foundational and the most in Portfolio.
